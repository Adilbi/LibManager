# LibManager — Система управления библиотекой

Консольное приложение на Java для автоматизации работы школьной или университетской библиотеки. Проект разработан с применением принципов объектно-ориентированного программирования (ООП).

## 🚀 Основной функционал
* **Управление пользователями:** Разделение прав доступа по ролям (Студент, Библиотекарь, Администратор).
* **Учет книжного фонда:** Добавление, удаление и поиск книг в системе.
* **Интерактивное меню:** Удобный консольный интерфейс для взаимодействия с системой.

## 🛠 Технологический стек
* **Язык разработки:** Java 11
* **Архитектура:** Объектно-ориентированная (инкапсуляция, наследование классов пользователей).
